# Title: Inventory Management System

## Purpose: 
GUI based inventory management desktop application that allows users to Add, update, and delete parts and products as well as search functionality.

## Author:  
Juan Aparicio  
Contact: japari6@wgu.edu  
V 0.0.1   Date: 09-27-2024  

## Tech Stack  
Language: Java  
IntelliJ Community 2023.2.2  
Java JDK version 17.0.1  
JavaFX-SDK-17.0.6  

## Directions:  
Launch Inventory System app, main window with parts and products table will appear.
In the main window, each table displays parts and products buttons to add/modify/delete. Search fields can be used to search by name or ID. Add and modify buttons will redirect to forms. When adding parts or products, IDs are automatically generated.
